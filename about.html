关于「校易集」

一个校园闲置交换网站 · 纯前端实现 · 无需注册登录

一、为什么要做这个网站

每到学期末和毕业季，宿舍里都会堆起一批用不上又舍不得扔的东西：只翻过几遍的教材、 用了一年多的键盘、成色还不错的台灯。

它们对原主人已经没用了，对刚开学的同学却刚好需要。问题在于，想找的人不知道东西在哪， 想卖的人也不知道该卖给谁——信息卡在这一步，东西就只能被扔掉。

「校易集」想解决的就是这一步：把本校同学的闲置集中到一个页面上，让需要的人能搜到、 能直接联系、能在食堂门口当面完成交易。不注册、不收费、不用寄快递， 这也是它相对二手电商平台最大的好处——同校面交，当场验货，风险最低。

二、网站包含哪些功能

🏠首页轮播图、分类入口、热门与最新
🔍闲置列表分类筛选、关键词搜索、四种排序
📄商品详情成色、地点、卖家信息、同类推荐
📝发布闲置表单校验、成色选择、自动算折扣
💛我的收藏与我发布的内容管理

三、技术实现说明

技术栈：HTML5 + CSS3 + 原生 JavaScript（ES6），不使用任何框架和第三方库， 也不需要安装环境——双击 index.html 即可在浏览器中运行。

样式：用 CSS 自定义属性（变量）统一管理配色，一套变量同时驱动浅色与深色两种主题； 布局使用 Flex 与 Grid；通过媒体查询适配平板和手机，小屏幕下导航自动收进抽屉菜单。

交互：商品列表由 JavaScript 动态渲染，支持分类筛选、关键词搜索（输入防抖 200 毫秒）、 价格与时间排序；收藏与"我发布的"商品使用浏览器 localStorage 保存，刷新和换页都不会丢。

表单：发布页面用一张「校验规则表」统一管理六个字段的校验逻辑， 输入时实时消除错误提示、失焦时校验，全部通过后才写入数据并跳转。

文件结构：6 个 HTML 页面 + 1 个公共样式表 + 2 个 JavaScript 文件， 所有页面共用同一套头部导航和页脚，保证视觉统一。

四、功能与考核点对照

考核点 本站对应的实现
设计目的 面向校园闲置交换，解决"东西卖不掉、想要找不到"的问题，全站内容围绕同一主题
跳转 6 个页面互相连通：导航栏、面包屑、分类入口、卡片跳详情、返回列表、页脚链接、返回顶部

CSS 变量与主题、Flex/Grid 布局、卡片悬浮动效、渐变封面、卡片依次淡入、响应式媒体查询
整体效果 统一的青绿色视觉、一致的圆角与阴影规范、每个分类有固定配色、深色模式、空状态提示

五、交易安全提示

1. 优先选择校内人流密集处当面交易，比如食堂门口、宿舍楼下、图书馆大厅。

2. 电子产品务必当面试用，耳机、键盘、音箱都可以现场连接手机测试。

3. 不要提前转账、不要扫来源不明的二维码，钱货两清最稳妥。

4. 泄露个人隐私的物品（学生证、快递单、含姓名学号的资料）请勿上架。
